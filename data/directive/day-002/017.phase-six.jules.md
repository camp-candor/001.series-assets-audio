#### 2. Durable Object Lease Coordinator (`apps/worker/src/durable_objects/AudioLeaseDO.ts`)

Implement `AudioLeaseDO`:
- Maintains in-memory / durable storage state for `{ activeLeaseHolder: string | null; leaseExpiresAtMs: number; highestCommittedVersion: number }`.
- `acquireLease(holderId: string, requestedVersion: number, nowMs: number, ttlMs = 60000)`:
  - If an unexpired lease is held by a different `holderId`, return `{ granted: false, statusCode: 'LEASE_CONFLICT_BREACH', httpStatus: 409 }`.
  - If `requestedVersion !== highestCommittedVersion + 1`, return `{ granted: false, statusCode: 'MONOTONIC_REGRESSION_BREACH', httpStatus: 409, expectedVersion: highestCommittedVersion + 1 }`.
  - Otherwise grant lease and persist state.
- `commitVersion(holderId: string, versionNumber: number)`:
  - Verifies active lease ownership, advances `highestCommittedVersion = versionNumber`, clears active lease, and returns `{ committed: true, versionNumber }`.
